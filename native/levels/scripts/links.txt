# The Rehabilitation Ward vestibule: the cyan door takes the Cherub Key.
# In the game the ward's door is bolted and only Leon's chainsaw cuts it
# (guides4gamers "Rehabilitation Ward Door", IGN, Rectify Gaming). This map
# has no stairs from the F2 central hall down to the F1 one, so the ward is
# Grace's only way from the F1 landing (141,240) into the Central Hall: it
# stays a plain door here. The fuse powers only the F2 gate (progression.txt).
setnear door 126 224 2 state=locked link=Cherub_Key name=cherub_door
setnear door 132 223 2 state=unlocked name=Rehabilitation_Ward_Door
setnear door 162 179 2 name=security_door
